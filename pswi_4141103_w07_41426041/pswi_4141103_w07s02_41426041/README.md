1. Navigasi Konsisten
    Kegunaannya adalah untuk menjaga kenyamanan dan kemudahan pengguna saat menjelajahi situs web. Dengan struktur menu yang seragam dan penanda halaman aktif yang jelas di setiap halaman, pengguna tidak akan merasa bingung atau tersesat. Selain itu, memastikan fungsi tautan serta tombol Back dan Forward berjalan normal membantu navigasi antarhalaman terasa lancar dan intuitif.

2. Path annd Aser
    Kegunaannya adalah untuk memastikan seluruh tampilan dan media situs web—seperti gaya CSS dan gambar—dapat dimuat dengan sempurna di server mana pun tanpa kendala. Dengan menggunakan path relatif dan menghindari path drive lokal komputer, proyek situs web Anda menjadi fleksibel untuk dipindahkan atau diunggah ke internet tanpa risiko file tidak ditemukan (error 404).   

3. Audit Dan Keseluruhan 
    Kegunaannya adalah sebagai tahap kontrol kualitas (penjamin mutu) untuk memastikan situs web bebas dari kesalahan teknis sebelum resmi dirilis. Pemeriksaan ini menjamin situs web dapat diakses oleh semua pengguna (termasuk yang menggunakan navigasi keyboard), tampilannya tetap rapi di berbagai ukuran layar dan tingkat zoom, serta kode HTML-nya valid tanpa ada tautan yang rusak.
