Refleksi fungsi HTML, CSS, dan JavaScript
 Refleksi saya mengenai HTML
    pemahaman saya mengenai penggunaan HTML adalah HTML berfungsi untuk menjadi struktur utama dalam membuat web.
    HTML sebagai fondasi utama dari pembuatan situs web. mulai dari pembuatan kerangka seperti judul, sub judul, dan isinya. HTML juga berfungsi unttuk menyabungkan CSS dan JS.

Refleksi saya mengenai CSS
    Yang saya mengerti mengenai CSS adalah CSS berfungsi untuk memberikan Gaya ataupun hiasan untuk halaman Web bisa seperti pemberian warna, penambahan fitur, dan masih banyak lagi. Jadi intinya CSS di pergunakan untuk menghias halaman web kita.

Refleksi saya mmengenai JavaScript
    JavaScript adalah fitur yang digunakan untuk membuat fitur-fitur yang seperti contohnya dihalam web ini setelah kita memasukan "<button type="button" id="greeting-button">Tampilkan salam</button>" kita juga harus memasukan bahasa computernya juga ke JavaScript supaya code nya berjalan. Jadi, intinya JavaScript berfungsi untuk menambah fitur interaksi di dalam web.
